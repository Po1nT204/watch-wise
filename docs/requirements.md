Требования к проекту

**Проект:** WatchWise
**Тип:** Web-платформа / Educational Technology (EdTech)
**Роль автора:** Fullstack-разработчик

## 1. Общее описание

Разработка интерактивной веб-платформы, трансформирующей пассивный просмотр образовательных видео (YouTube, VK Video) в активный процесс обучения. Система автоматически генерирует учебные материалы (конспекты, тесты, карточки) и внедряет механики «Умной паузы» непосредственно в видеоплеер, используя технологии искусственного интеллекта. Платформа предусматривает сценарии использования как для студентов (самообучение), так и для преподавателей (подготовка материалов).

## 2. Цели и Задачи ВКР

1.  **Архитектурное проектирование:** Реализация масштабируемого веб-приложения на базе Next.js с строгим разделением логики и представления (слои `services`, `hooks`, `features`).
2.  **Интеграция AI-пайплайна:** Разработка системы асинхронной обработки медиа-данных: извлечение потока (yt-dlp), сохранение в S3, распознавание речи (SpeechKit) и генерация семантического контента (YandexGPT).
3.  **Frontend-инженерия:** Создание интерактивного интерфейса видеоплеера, синхронизированного с данными транскрипта и тестов в реальном времени.
4.  **Работа с данными:** Проектирование реляционной базы данных для хранения контента, глобальных тегов и геймифицированного прогресса пользователей (XP, Уровни).

## 3. Функциональные требования (FR)

### 3.1. Аутентификация и Пользователи

- **Регистрация и Вход:** Реализация через NextAuth.js (email + пароль / Google OAuth).
- **Сессии:** Использование Database Strategy (сессии в БД) для обеспечения безопасности и контроля.
- **Геймификация:** Начисление опыта (XP), расчет уровней и отслеживание дней активности подряд (стрики).

### 3.2. Обработка видео (Core Logic)

- **Ввод данных:** Парсинг ссылок на YouTube и VK Video.
- **Настройка генерации:** Выбор параметров перед запуском:
  - Сложность вопросов, количество вопросов.
  - Целевая аудитория (школьник, студент, эксперт) и фокус анализа (теория, практика, факты).
- **Управление медиа:** Загрузка видео- и аудиодорожек в объектное хранилище (S3).

### 3.3. Технический пайплайн обработки

- **YouTube / VK Video:** Скачивание аудио и видео (в 480p) на сервер через `ytdlp-nodejs`.
- **SpeechKit (ASR):** Отправка аудио на распознавание, поллинг статуса, формирование транскрипта с временными метками.
- **YandexGPT (LLM):** Генерация структурированного JSON (Summary, Quiz, Flashcards, Tags) и его обязательная валидация через Zod-схемы.

### 3.4. Режимы использования

- **Режим «Студент»:**
  - **Конспект:** Чтение структурированного текста с навигацией по кликабельным таймкодам.
  - **Умная пауза:** Автоматическая остановка плеера в момент появления вопроса.
  - **Интерактив:** Мгновенная визуальная обратная связь, пояснения от ИИ при ответе.
- **Режим «Преподаватель»:**
  - Редактирование или удаление сгенерированных вопросов и вариантов ответов.

## 4. Нефункциональные требования (NFR)

### 4.1. Технологический стек

- **Frontend:** Next.js 15 (App Router), React, TypeScript.
- **Styling:** Tailwind CSS, shadcn/ui.
- **State Management (Client):** Zustand (для легкого стейта: счетчик очков).
- **Backend:** Server Actions, API Routes.
- **Database:** PostgreSQL + Prisma ORM.
- **Infrastructure:** Docker (БД), Yandex Cloud (Object Storage, AI).

### 4.2. Производительность и Надежность

- **Асинхронность:** Длительные процессы выполняются в фоне.
- **Отказоустойчивость:** Использование библиотеки `p-retry` для повторных попыток при сетевых сбоях (Exponential Backoff).
- **Логирование:** Структурированное логирование всех процессов на сервере с помощью `pino`.
