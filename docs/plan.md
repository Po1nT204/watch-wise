## Реальные отклонения от плана (Проблемы и решения)

1. **Проблема:** YandexGPT периодически возвращал невалидный JSON с пояснительным текстом.
   **Решение:** Внедрена жесткая валидация через `Zod` (AIGeneratedContentSchema) и алгоритм очистки строки с помощью регулярных выражений для извлечения сырого JSON из ответа модели.
2. **Проблема:** VK Video не отдает аудио-поток по простому API для распознавания.
   **Решение:** Разработан сложный пайплайн: использование `ytdlp-nodejs` для локального скачивания аудиофайла -> загрузка файла в Yandex Object Storage (S3) -> передача ссылки в асинхронное API SpeechKit -> поллинг (опрос) готовности результата.
3. **Проблема:** Монолитность UI-компонентов.
   **Решение:** Проведен рефакторинг с вынесением сложной логики (парсинг таймкодов, работа плеера) в `src/lib/` и кастомные хуки `src/hooks/`, что позволило изолировать бизнес-правила от представления.
